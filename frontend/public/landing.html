Questions
Before you ask support
Can I migrate from Excel mid-month? +
Yes. Bulk-import employees via CSV at any point — attendance and leave balances can be backdated to the start of the current cycle so nothing's lost.
Does this replace my CA? +
No — and we'd recommend against that. The engine computes PF, ESI, PT and TDS correctly, but we still suggest a CA sign-off before your first live payroll run, the same way you'd review any new system.
What happens to our data if we cancel? +
You can export every record — employees, attendance, payslips — as CSV at any time. We retain a backup for 90 days after cancellation, then delete it.
Can each department see only their own people? +
Yes. Managers see their direct reports; HR admins see everyone. Role-based access is built into every module, not bolted on.
